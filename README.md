# multicultural-meal-planner
This is a multicultural meal planner tool which is built using data migration and analysis and is aimed at busy parents facing daily challenges in deciding what nutritious food to prepare and cater to their family's taste. The tool helps to blend Indian traditional cooking with European ingredients while keeping meals balanced for growing children which is a daily puzzle. This tool helps to track nutritional values, weekly grocery shopping lists, and meal rotation history without repeating the same meals or missing dietary requirements.
